# Онлайн-обучение

## Описание:

Данный проект разрабатывался в рамках домашней работы и содержит следующий функционал:
1. Создание пользователя и его авторизация;
2. Создание курсов и уроков (с возможностью изменяния/удаления только авторам),
   Просмотр доступен только для своих курсов и уроков;
3. Создание подписок
4. Информирование по почте об изменении курса пользователя при наличии подписки;
5. Создание и проведение оплаты курса.


## Установка:

### 1 Способ
1. Клонируйте репозиторий
   (`git clone`) [GitHub](https://github.com/SuchkovaMaria/HW_DRF)
2. Установите зависимости
   (`pip requirements.txt`)

### 2 Способ
1. Клонируйте репозиторий
   (`git clone`) [GitHub](https://github.com/SuchkovaMaria/HW_DRF)
2. Заполните файл .env переменными согласно примеру указанному в .env.example
3. Запустите все сервисы 
    ```bash docker-compose up -d```
4. Дополнительные фозможности:
остановка всех сервисов
    ```docker-compose stop```;
Запуск после остановки
```docker-compose start```.

## Использование:

1. Откройте проект.
2. Запустите проект.
3. Откройте в браузере сайт по ссылке интернет магазина [sky_store](http://127.0.0.1:8000/)
